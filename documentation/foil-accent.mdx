In order to use our plugin, it requires you to have [Woocommerce](https://woocommerce.com/woocommerce/) installed on your WordPress admin. Follow these steps to install WordPress, then WooCommerce and finally GleamPrint.

1.  Download and install WordPress: [http://wordpress.org](https://wordpress.org/)
2.  After installing WordPress, login to your WordPress admin portal and install WooCommerce.

    To do this, you can either install manually or install within the WordPress admin panel by searching for “WooCommerce” in the Plugins -> Add New -> and then search field.

    Optionally, you can download it manually here: [http://downloads.wordpress.org/plugin/woocommerce.zip](http://downloads.wordpress.org/plugin/woocommerce.zip) and install manually if you so choose.

3.  Once, you have installed both WordPress and WooCommerce, you can then install GleamPrint through the same procedure as above. Search for “Gleamprint” in Plugins -> Add New -> and then type “GleamPrint” into the search field.
4.  Activate both the WooCommerce and GleamPrint plugins under Admin -> Plugins -> Installed Plugins.
5.  GleamPrint mainly focuses on products created through woocommerce, so you need to create a product. Go to Products -> Add New -> and then start creating your product, once you've added all the necessary information like Title, Description, Price etc. You should now set a product image, when setting a product image be sure to set one that has a cut out section, because GleamPrint will then be creating a foil accent behind the product image.
6.  On the right side of the Add New Product section you'll find the following. Choose the gradient you prefer, be sure to either give your product the light reflection movement or can you keep it simple yet elegant.

    ![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/6638ac075027f87fcc6be32d/file-02Cgt9TOsY.png)

7.  When you've decided on the gradient and also the animation state, you can now publish your product. It should resemble the following.

    ![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/6638b5545027f87fcc6be330/file-y2hCTjB6Ot.png)
