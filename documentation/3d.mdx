PitchPrint 3D View allows you to view a model from a front and back perspective. In order to do this a two page design template design needs to be created and assigned to a 3D model. Page 1 will be the front of the business card and page 2 will be the back of the business card.

#### Creating a two page design in PitchPrint

1.  Navigate to [Designs](https://admin.pitchprint.com/designs) in the PitchPrint admin.
2.  Select the new design button and create a design that consists of two pages.

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/62a079ec02b8fd3b945fb4a6/file-Wk0nbtlQ0Q.png)Page 1 will be the front of the business card.

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/62a07a4957320007925228e2/file-gWLfeMtEs7.png)

Page 2 will be the back of the business card. Select the Preview button on the top right and submit the design.

#### Creating a texture image for a business card

1.  ![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/5dd254732c7d3a7e9ae4100f/file-aG9VpHINZu.png)

    Create a canvas of 1024x1024 in any design software such as Adobe Illustrator, Photoshop etc.

2.  The canvas needs to be divided into two sections, a top and bottom section.

3.  Create two rectangular blocks of equal size.

4.  The front of the business card design will be placed on the top half of the canvas and the back of the business card will be placed on the bottom half of the canvas.

5.  Open the artwork you want to apply to the 3D model in a design program and place the front of the business card design on the top half of the canvas and the back of the business card design at the bottom of the canvas.

6.  Save the file as a PNG.

7.  This texture file will replace the default image when selecting the change texture file button.

#### UV Mapping the 3D model

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/5dd7bfea2c7d3a7e9ae44adc/file-wuYyh7bbHL.png)

The UV Mapping of the model should be identical to the texture file created in the above step. 

**Uploading your Mesh**

Navigate to the  [3D studio](https://admin.pitchprint.io/three)  and select the upload your mesh button. Select the obj file of your choice. 

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/62a0755d02b8fd3b945fb485/file-cf5nlO25gM.png)

Once the mesh is uploaded select the change texture file button and replace the default image with the texture file of 1024x1024.

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/62a0752992cb8c175b46ad57/file-fLZ3o0Rpax.png)

Once the texture file is uploaded it will display as below. Click save ![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/62a07c0d92cb8c175b46ad86/file-ACFVvQcnRr.png)

#### Assigning a design to the model

Navigate to [Designs](https://admin.pitchprint.com/designs) in the PitchPrint admin and hover over the 2 page design you created for the business card and select the configuration button. 

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/62a07db8e1d2cf0eac00ef81/file-indfWvnmc4.png)

Select 3D view and select the model you want to assign the design to and save.

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/62a07e2e02b8fd3b945fb4d9/file-mgMWiHwFbq.png)

#### **Configuring the model**

Navigate to [3D studio](https://admin.pitchprint.io/three) and click on the uploaded model and select the edit button. 

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/62a07db8e1d2cf0eac00ef81/file-indfWvnmc4.png)

Once the editor is displayed select the show configuration button.

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/62a0777657320007925228d6/file-fGjC4pFCWc.png)The below image will be displayed once selecting the button. This helps to set the artwork boundary areas of the design. 

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/5dd2599d04286364bc91daec/file-MStozT84vp.png)

In the Search designs tab. Copy the name of the 2 page design you assigned to the model and press enter.

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/5dd25a1504286364bc91daef/file-o2NAExGJwd.png)

Once you press enter the design name will show by the selection box. Select the design of your choice and select page 1 and set the boundary boxes to the top half of the texture file.

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/62a0814002b8fd3b945fb502/file-CF4eCK5hB1.png)Select Page 2 and set the boundary boxes to the bottom half of the texture file.

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/62a0825ba2c316231c203e55/file-NteZ02SF2H.png)

Select the hide configuration button and you will be able to see how the texture file displays on the front and back of the model. Auto rotate allows you to see the model from various perspectives. Click save on completion.

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/5dd2595e04286364bc91daea/file-8cc94snVJ4.png)
