Here are instructions to help you install PitchPrint on BigCommerce:

1.  Sign up to BigCommerce and create your own account [https://www.bigcommerce.com/apps/pitchprint/?search=pitchprint](https://www.bigcommerce.com/apps/pitchprint/?search=pitchprint)
2.  Click on get this app [https://store-togng4uxq9.mybigcommerce.com/manage/marketplace/apps/22128](https://store-togng4uxq9.mybigcommerce.com/manage/marketplace/apps/22128)
3.  Click on the install button [https://store-togng4uxq9.mybigcommerce.com/manage/app/22128](https://store-togng4uxq9.mybigcommerce.com/manage/app/22128)
4.  Log into your PitchPrint account [https://login.bigcommerce.com/login](https://login.bigcommerce.com/login)
5.  if you do not have an account then register [https://www.bigcommerce.com/essentials/free-trial/?\_ga=2.180235812.1824908394.1599555564-1960830094.1599555564](https://www.bigcommerce.com/essentials/free-trial/?_ga=2.180235812.1824908394.1599555564-1960830094.1599555564)
6.  Select the installation plugin you intend on using

    ![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/5f57b5344cedfd00176328a3/file-B7u7jDBt8M.png)

7.  Once you select the plugin you can import designs, create a new design, assign assets and create a product.
