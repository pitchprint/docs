Use this endpoint to fetch all projects linked to a user.

**\[POST\]** [https://api.pitchprint.com/runtime/fetch-user-project](https://api.pitchprint.com/runtime/fetch-user-project)

**BODY PARAMS**

<table class="hs-table"><colgroup><col width="282"><col><col></colgroup><tbody><tr><td style="width: 282px;">Secret Key</td><td>Your domain's secret key</td></tr><tr><td>userId</td><td>The unique <strong>userId</strong> of the user.</td></tr></tbody></table>

* * *

**SAMPLE CODE**

curl --location 'https://api.pitchprint.com/runtime/fetch-user-projects' \\
--header 'Authorization: secr\_jBlUI0uksoZgXlQq4igUSRoUs#AfVF' \\
--header 'Content-Type: application/json' \\
--data '{
    "userId": "5629946986554"
}'
