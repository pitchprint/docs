**PitchPrint** has a feature called **chain,** which basically allows you to link items on the canvas to each other, Such that when one item is edited, all other items with the same chain ID gets the same colour value.

**For Colour chains use the following values: col1, col2, col3, col4, col5, col6, col7, col8, col9 and col10**

So an element with any of the above values is deemed a color chain.
