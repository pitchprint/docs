---
title: "How to save your SVGs for use in PitchPrint"
description: "To create PitchPrint optimized SVG files, kindly follow these steps"
---

To create PitchPrint optimized SVG files, kindly follow these steps

1.  Open your SVG file in Adobe Illustrator
2.  Select the element you want to export as SVG, be it a group or single element.
3.  Go to Edit > Copy or _(Ctrl + C / Cmd + C)_ to copy it into your clipboard
4.  Launch a text editor like NotePad, SublimeText or [Brackets](http://brackets.io). Create a blank new file in the text editor and paste the copied data into it. **_Please do not use a word processor for this. It will not work._**
5.  This will paste the exact SVG code into the editor. You may need to delete the last extra line added.
6.  Save the editor file with an **_svg_** extension and you can import it into PitchPrint.

> Kindly note, gradients are not yet supported on PitchPrint at the moment but it's something we will have in the near future.
