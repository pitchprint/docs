**Page Clip:** A feature that allows you to add any shape to the canvas and set it as a clip to cut area around the shape in the final PDF.

To enable page-clip, click on the shape and go to the ITEM menu tab. Add **_page-clip_** to the tag section as shown below and enable make reference.

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/65099e4b96b8220e08ace215/file-5DQChhpROs.png)

The below image will be the output thereafter:

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/65099e7096b8220e08ace216/file-uGRm7hnLOl.png)

**Always Top:** Allows you to place an element at the topmost layer of the canvas.

To enable always-top add the **_always-top_** tag to the tag section as shown below:

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/6509a06f302287021e634a1e/file-jcuAhWc1Uc.png)

This will result in all other elements moving behind the item selected and that selected element will remain at the top irrespective of edits implemented on the design.

**Always Bottom:** Allows you to place an element in the lowest layer of the canvas.

To enable always-bottom add the **_always-bottom_** tag to the tag section as shown below:

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/6509a276e249755d2f85c270/file-uaE9GOK9Tg.png)

This will result in all other elements moving in front the item and selected item will always remain at the bottom.

**PDF no-print** - The item will not be displayed on the printed file. To enable pdf: no-print add the following tag shown below:

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/6509a338b57bfa3b524b12a2/file-u9wZLeqyEm.png)

**PDF no-view** - The item cannot be viewed when you open the PDF inside any PDF viewing application. To enable pdf: no-view add the following tag shown below:

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/6509a35b96b8220e08ace219/file-MmkbTuV37m.png)

**PDF lock** - The item cannot be moved when editing the PDF. To enable pdf: lock add the following tag shown below:

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/6509a39e96b8220e08ace21b/file-IWNgYDGhCW.png)

**Disable Text anchors**: This tag will disable the text anchors when applied to a text field. To enable disable text anchors please add the following tag shown below:

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/6509a3f0302287021e634a2b/file-6qFgLTBq3n.png)

**Grommets:** A reinforcement hole either horizontally or vertically used to insulate a rope or cable passed through it. A great way to protect the design material from tearing or abrasion. To enable grommets please follow the steps below:

Go to the page section as shown below and enable the Grommet on the page tags:

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/6509a8d1b57bfa3b524b12ba/file-VyJ5IOgNGA.png)

Add the tag as indicated on the screenshot above.

Kindly note for Horizontal values, any value can be added as for Vertical only 1 OR 2 may be used. Please note that any changes made to the top of the page will be automatically added to the bottom as well.

**No-mask:** Allows you to stop a shape from being used as an image placeholder. Any shape added to the canvas will be used as an image placeholder by default. If you would like to prevent customers from adding images to shapes on the canvas, you do so by enabling _no-mask_ and it will prevent the shape from being used as an image placeholder.

To enable no-mask please add the tag as shown below:

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/6509aa19302287021e634a36/file-KWAOfQA8mA.png)
