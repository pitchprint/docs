---
title: "Adding Pages Programmatically"
description: "To add a page programmatically we make use of the clone-page event."
---

To add a page programmatically we make use of the _clone-page_ event.

	app.events.fire('clone-page', pageNum);

PageNum is actually the index of the page that should be cloned, a page ID can also be used instead of page index.
