---
title: "Render PDF & Raster"
---

At the moment, all PDF and Raster files are being rendered at runtime.

**[GET]** `https://pdf.pitchprint.com/{projectId}`

To get the PNG raster, simply use the `png` or `jpeg` subdomains.

**[GET]** `https://png.pitchprint.com/{projectId}`

##### PATH PARAMS

| Parameter | Description |
| --- | --- |
| `projectId` | ID of the project to render |
