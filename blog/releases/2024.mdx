It transforms rough hand-drawn sketches into polished, high-quality outputs with precise control.   ### Save edited image

  Previously, we only saved the AI-generated image and did not always retain the original image to which the filter was applied. However, we’ve made an update to improve this process. Now, both the generated image and the original image with the applied filter are available in the Uploads tab.

  <AccordionGroup>
    <Accordion title="Bug fixes" icon="bug">
      ### Color panel cut off

      We identified an issue where the color editor in the admin panel would be cut off when editing colors near the bottom of the webpage. This issue has now been resolved, and all color editing pop-ups will display fully within the browser window.

      ### Pixabay scroll issue

      We identified an issue where, after performing a search on Pixabay and scrolling, the scroll position wouldn’t reset to the top when initiating a new search.   Previously, our system would segregate all records from the CSV and place each record into a separate file. We have now introduced an option that allows the admin to download all records into a single print file, offering enhanced convenience and efficiency. By default, the records will still be segregated into individual files, but once the admin enables this new functionality, all records will be consolidated into one file. Please follow the steps below to enable this amazing new feature:

  </Frame>

  ### Edit product in Cart on Shopify

  In the past, once a customer clicked the “Add to Cart” button after customizing a product, they had limited options — either they would leave the item as is or start over if they missed something or made a mistake. We’ve listened to your feedback, and we’re excited to introduce the **Edit from Cart** functionality on **Shopify**.

  Now, customers can easily make changes to their customization directly from the cart if they forgot something or need to correct an error. This new feature not only enhances the customer experience but also contributes to better retention and reduces the need for refunds on orders.   We have introduced a new functionality that automatically sorts design files alphabetically and numerically. This feature will be available to all accounts by default.

This will help identify and resolve any issues before purchase, ultimately reducing the burden on administrators.

  **Runtime Endpoint to Fetch User projects, Move customize button, Add product to Cart.**

  We are pleased to update you on the recent efforts of our team to enhance your experience on PitchPrint.

  ### Runtime Endpoint to Fetch User projects

  We added an exciting new feature which allows an admin to fetch user projects with the help of the userId. To make use of this feature please use the following endpoint [https://api.pitchprint.com/runtime/fetch-user-projects](https://api.pitchprint.com/runtime/fetch-user-projects). Then use your **Secret key** as an **Authorisation** in the **header**. Your secret key can be found on the following [link](https://admin.pitchprint.com/domains). Additionally you need to pass the **userId** as **JSON** in the **body**. Please have a look at an example with cURL below:

  curl --location '[https://api.pitchprint.com/runtime/fetch-user-projects](https://api.pitchprint.com/runtime/fetch-user-projects)'
  \--header 'Authorization: &3SQxBRONb#aa(^uiC@v\*4aM8DkQR^'
  \--header 'Content-Type: application/json'
  \--data '\{
  "userId": "5629946986554"
  \}'

  ### Move customize button
