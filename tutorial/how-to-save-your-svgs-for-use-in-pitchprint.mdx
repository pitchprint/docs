---
title: "How to save your SVGs for use in PitchPrint"
description: "Copy artwork out of Adobe Illustrator into a plain text editor and save it as an .svg file that PitchPrint can import"
---

To create PitchPrint optimized SVG files, kindly follow these steps

<Steps>
  <Step title="Open the file in Illustrator">
    Open your SVG file in Adobe Illustrator
  </Step>
  <Step title="Select the element to export">
    Select the element you want to export as SVG, be it a group or single element.
  </Step>
  <Step title="Copy it to your clipboard">
    Go to Edit > Copy or _(Ctrl + C / Cmd + C)_ to copy it into your clipboard
  </Step>
  <Step title="Paste into a plain text editor">
    Launch a text editor like NotePad, SublimeText or [Brackets](http://brackets.io). Create a blank new file in the text editor and paste the copied data into it. **_Please do not use a word processor for this. It will not work._**
  </Step>
  <Step title="Tidy up the pasted code">
    This will paste the exact SVG code into the editor. You may need to delete the last extra line added.
  </Step>
  <Step title="Save with an .svg extension">
    Save the editor file with an **_svg_** extension and you can import it into PitchPrint.
  </Step>
</Steps>

<Warning>
  Kindly note, gradients are not yet supported on PitchPrint at the moment but it's something we will have in the near future.
</Warning>
