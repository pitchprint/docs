---
title: "Image Chain"
---

**PitchPrint** has a feature called **chain,** which basically allows you to link items on the canvas to each other. Such that when one clickable mask is edited, all other clickable masks with the same chain ID gets the same image uploaded into it.

**For Image chains use any numeral values.**
