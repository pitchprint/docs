Every design has its own configuration panel, split into five tabs. This page documents each option in the order it appears.

## General

<ResponseField name="Title" type="text">
  Your design title.
</ResponseField>

<ResponseField name="Welcome Message" type="text or HTML">
  The message shown when the app loads. Accepts plain text or HTML.
</ResponseField>

<ResponseField name="Tags" type="text">
  Add [tags](/documentation/tags) that extend the functionality of the editor.
</ResponseField>

<ResponseField name="Show Customize Form" type="toggle">
  Displays a form containing every element in the design when it loads. Customers fill in the form and the design updates from their input.

  <Warning>
    If a Welcome Message is also enabled, this form overrides it.
  </Warning>
</ResponseField>

<ResponseField name="Hide Tabs" type="multi-select">
  Hide the Backgrounds, Pictures or Text tabs. Selected tabs are not visible to the customer.
</ResponseField>

<ResponseField name="Lock Background" type="toggle">
  Prevents customers from changing the background.
</ResponseField>

<ResponseField name="Only Drag an Image to Masks" type="toggle">
  Disables click-to-add for images. Images can only be added by dragging and dropping them into masks.
</ResponseField>

<ResponseField name="Auto Place Image in Masks" type="toggle">
  Uploaded images are placed into available masks automatically. Only masks on the canvas are filled — with 5 masks and 6 uploads, the first 5 images fill the masks and the 6th is added straight to the canvas.
</ResponseField>

<ResponseField name="Snap to Page Only" type="toggle">
  Items snap only within the page boundaries and cannot extend beyond them.
</ResponseField>

<ResponseField name="Uploaded Image Operations" type="select">
  Convert uploaded images to **grayscale** or **black & white**, and apply **ICC profiles**.
</ResponseField>

<ResponseField name="Client PDF Download" type="toggle">
  Lets customers download the PDF directly from the app.
</ResponseField>

<ResponseField name="Split Masks" type="toggle">
  Splits every clickable mask in the design into a separate PDF page.
</ResponseField>

<ResponseField name="Chain Colors" type="toggle">
  Syncs colors across elements sharing a chain ID. Changing one item's color updates every item in the same chain. See [colour chains](/tutorial/how-to-create-colour-chains).
</ResponseField>

<ResponseField name="Disable Drag Select" type="toggle">
  Stops customers dragging to select multiple items at once.
</ResponseField>

<ResponseField name="DPI Check" type="toggle">
  Enables the [DPI check](/tutorial/photo-resolution-check) for this design.
</ResponseField>

<ResponseField name="Flash Item Dimensions" type="toggle">
  Shows an item's physical dimensions while it is being resized.

  <Note>
    Not available for text items — it applies to all other item types.
  </Note>
</ResponseField>

<ResponseField name="Show Image Picker on Load" type="toggle">
  Opens the image source picker automatically when the editor loads.
</ResponseField>

<ResponseField name="DPI Value" type="number">
  The minimum DPI images must meet for this design.
</ResponseField>

<ResponseField name="New Text Color" type="color">
  The color applied to new text added to the canvas.

  <Warning>
    Provide both the **RGB** and the **CMYK** value, or the PDF output will be wrong.
  </Warning>
</ResponseField>

<ResponseField name="Thumbnail Image" type="image">
  Used in the [Design Selector](/tutorial/design-selector-module) in place of the original design preview.
</ResponseField>

<ResponseField name="Default Font" type="select">
  The font applied to text in the design by default. See [adding your own fonts](/tutorial/how-to-add-your-own-fonts).
</ResponseField>

<ResponseField name="Default Tab" type="select">
  The tab that opens first when the designer loads.
</ResponseField>

<ResponseField name="Default Background Mode" type="select">
  The mode applied to new background images added to the design.
</ResponseField>

<ResponseField name="Unit" type="select">
  The unit of measurement used throughout the design.
</ResponseField>

<ResponseField name="Limit Text Characters" type="regex">
  Controls which characters customers can type. Enter a valid Regex pattern defining the allowed characters.
</ResponseField>

<ResponseField name="Minimum Font Size" type="number">
  The smallest font size customers may use for text in the design.
</ResponseField>

## Resources

Manage which resources are available inside the design — include or exclude them individually, or apply the change to all at once.

Applies to **Pictures**, **Backgrounds**, **Fonts**, **Text Arts** and **Colors**.

## Modules

Modules add optional behaviour to a design. Each has its own guide:

<CardGroup cols={2}>
  <Card title="Page Count" icon="hashtag" href="/tutorial/how-to-use-page-count-module">
    Links your site's quantity element to the number of pages in the design, updating it automatically.
  </Card>
  <Card title="Page Loader" icon="copy" href="/tutorial/page-loader-module">
    Lets customers add, remove, sort and swap pages within the design.
  </Card>
  <Card title="Canvas Adjuster" icon="up-right-and-down-left-from-center" href="/tutorial/canvas-adjuster-module">
    Syncs dimensions between your product page and the editor, using preset or custom values.
  </Card>
  <Card title="Data Form" icon="table-list" href="/tutorial/data-form-module">
    A quick-edit form for changing canvas items without touching the canvas.
  </Card>
  <Card title="Photo Prints" icon="images" href="/tutorial/photo-print-module">
    Bulk Photo Print, Vintage Photo Prints, and Photo with Paper Type.
  </Card>
  <Card title="Template Color" icon="palette" href="/tutorial/template-color-module">
    Lets customers change the color of the template image inside the design.
  </Card>
  <Card title="Swatch" icon="swatchbook" href="/tutorial/swatch-module">
    Offer different color combinations per layer of a design.
  </Card>
  <Card title="Remix" icon="shuffle" href="/tutorial/remi-module">
    Lets customers remix and swap the images in a design.
  </Card>
  <Card title="Variable Data" icon="file-csv" href="/tutorial/variable-data-module">
    Prepopulate a design from an uploaded Excel or CSV file.
  </Card>
  <Card title="Single/Double Sided" icon="file-lines" href="/tutorial/single-double-sided-module">
    Lets customers start with a single page or a double-sided layout.
  </Card>
</CardGroup>

<Note>
  **Canvas Adjuster** and **Page Count** behave differently across ecommerce frameworks. Canvas Adjuster currently has native support for **drop-downs only**.
</Note>

### Photo Prints categories

<ResponseField name="Photo with Paper Type" type="category">
  Offers customers a choice of size and paper type.
</ResponseField>

<ResponseField name="Bulk Photo Prints" type="category">
  Lets customers order multiple quantities of each photo they upload.
</ResponseField>

<ResponseField name="Vintage Photo Prints" type="category">
  Uses the customer's uploaded photo as the design itself. The image fits the page it is placed on, matches that design's dimensions, and stays editable.
</ResponseField>

<Note>
  Values and options selected in the editor cannot currently be synced back to the product page — but they **are** included in the PDF bookmarks.
</Note>

## History

Each time a design is saved, a new version is recorded. Use the history to review earlier versions and revert if a change went wrong.

## 3D View

Lists every 3D model available on the domain, so you can assign one to the design. See [3D views](/documentation/3d-view-introduction).
