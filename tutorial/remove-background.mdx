title: "Remove Background"
description: "Switch on the AI background removal button in the editor by resaving your layout and styling in the admin."
---

  <img src="https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/657f6bf9a126ca3c882e2dba/file-gQvWotzXhV.png" alt="Remove Background feature banner" />

This feature allows your customers to remove the background from an image within the PitchPrint editor. It saves the customer the need from using an external application to remove a background from their images. The feature is still in BETA phase and we're still in the process of training the AI on a daily basis.

To enable Remove Background please go to the [Layouts page](https://admin.pitchprint.com/layouts). Please ensure that you **Copy** and **Paste** any changes like **Javascript, HTML or CSS** code you added on an external file. After doing so reload the layout please have a look at the image below:

<Frame>
  <img src="https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/6579b59ea6b35633719e13c3/file-olbtVtSemg.png" alt="Layouts page in the PitchPrint admin used to reload the layout" />
</Frame>

You can then paste your code back into the layout section and save.

After doing this please go to the [Styling page](https://admin.pitchprint.com/styling) and save styling.

<Frame>
  <img src="https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/6579b6a5df200d704d5dd8d7/file-TItFap4Ope.png" alt="Styling page in the PitchPrint admin ready to be saved" />
</Frame>

The button should then appear within the editor which allows the customer to remove the background please have a look at the image below:

<Frame>
  <img src="https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/6579b89719769d727a1b70e4/file-SjZtpuL7H0.png" alt="Remove background button available to the customer inside the editor" />
</Frame>

Please send us your questions and suggestions to [support@pitchprint.com](mailto:support@pitchprint.com) it will help us improve this functionality
