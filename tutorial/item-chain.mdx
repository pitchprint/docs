---
title: "Item Chain"
description: "Give canvas items a shared chain ID so editing one text item updates every other item linked to it."
---

**PitchPrint** has a feature called **chain,** which basically allows you to link items on the canvas to each other. Such that when one text item is edited, all other text items with the same chain ID gets the same text value.
