In this article, you will receive step-by-step instructions on how to import designs from the PitchPrint store to your own store.

1\. To start, first login to your PitchPrint store: https://admin.pitchprint.com/login which will take you to the dashboard.

2\. Next 'click' on **Designs** in the side panel:

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/652544c2c00c2b65208e2187/file-751SxHzVw3.png)

3\. Once the design page has loaded, Select the appropriate category you'd like to import the design/s into. (Lets use Canvas Prints as an example)

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/6525437f05231a0b51d238be/file-0tq16NgV2P.png)

4\. Now click on the **Import Designs** button:

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/6525438c05231a0b51d238bf/file-Ngz3utJ9lm.png)

5\. The following window will pop-up: You can use the drop down menu, to select a category you'd like to choose a design/s from

![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/61af05b764dede799a10733d/file-r2eS9Dvi9U.png)

6\. Once you have chosen a category, select the designs you want to import and then 'click' the I**mport Designs** button Its as easy as that.
