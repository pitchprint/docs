**VB Media** is an ecommerce platform that allows businesses to manage and sell products online. By integrating PitchPrint with VB Media, you can allow customers to personalize products using the PitchPrint online design editor. Once a customer completes their design and places an order, the design files are attached to the order for processing.

## Before You Begin

If you already have a PitchPrint account, you can proceed with the setup below.

If you don't have an account yet, [create a PitchPrint account](https://admin.pitchprint.com/register) and log in to access your API credentials.

## Step 1: Open your VB Media Admin configure Pitcprint

<Steps>
  <Step title="Log in to your VB Media Admin">
    Log in to your **VB Media Admin**.
    2.  Go to **Settings**.
    3.  Scroll down to **PRO**.
    4.  Select **PitchPrint** to open the configuration settings.

    ## Step 2: Add Your PitchPrint API Credentials
  </Step>

  <Step title="Log in to your PitchPrint Admin account">
    Log in to your PitchPrint Admin account.
    2.  Go to [Domains](https://admin.pitchprint.com/domains).
    3.  Copy your **API Key** and **Secret Key**.
    4.  Return to the PitchPrint configuration in your VB Media Admin.
    5.  Enter the API Key and Secret Key into the corresponding fields. Click **Save and Update**.

    3.  Go to the **Artwork** section.
    4.  Click **Select a PitchPrint design**.

## Step 4: Test the Integration

Once the product has been saved, visit your website and open the product.

You should now see the **Customize** button, allowing customers to open the PitchPrint editor and personalize the product.

If you experience any issues during setup or need assistance, please contact [PitchPrint Support](mailto:support@pitchprint.com).
