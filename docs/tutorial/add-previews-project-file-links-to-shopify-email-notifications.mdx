---
title: "Add previews & project file links to Shopify email notifications"
description: "Add PitchPrint design previews and PDF download links to the order emails your Shopify store sends."
---

Shopify's email templates can include the customer's PitchPrint preview image and a link to their print file. Both are added by pasting a Liquid snippet into the template.

<Steps>
  <Step title="Open your email templates">
    In your Shopify admin go to **Settings → Notifications**, then choose the email template you want the previews or links to appear on.
  </Step>

  <Step title="Find the line item block">
    Search the template for this code:

```liquid
     {% for line in subtotal_line_items %}
      <tr class="order-list__item">
        <td class="order-list__item__cell">
          <table>
            <td>
              {% if line.image %}
                <img src="{{ line | img_url: 'compact_cropped' }}" align="left" width="60" height="60" class="order-list__product-image"/>
              {% endif %}<br>
    ```
  </Step>

  <Step title="Add the preview image">
    Immediately below that block, paste:

```liquid
      {% for property in line.properties %}
        {% if property.first contains "_pitchprint" %}
          <img src="https://pitchprint.io/previews/{{ property.last }}_1.jpg" align="left" width="150" height="auto" class="order-list__product-image"/>
        {% endif %}
      {% endfor %}
    ```
  </Step>

  <Step title="Find the item title line">
    To add a PDF link as well, search for:

```liquid
    <span class="order-list__item-title">{{ line_title }} × {{ line_display }}</span><br/><br>
    ```
  </Step>

  <Step title="Add the PDF download link">
    Immediately below that line, paste:

```liquid
    {% for property in line.properties %}
     {% if property.first contains "_pprint-pdf-download" %}
        <a href="{{ property.last }}">Download PDF file</a>
     {% endif %}
    {% endfor %}<br>
    ```
  </Step>

  <Step title="Save and send a test">
    Save the template and use Shopify's **Preview** or send yourself a test order email to confirm the preview and link render.
  </Step>
</Steps>

<Note>
  Contact support if you need any further assistance with the above.
</Note>
