Depending on the context you are in, you either see the page panel or the item panel as shown:

## Page Panel

Fields available when you are creating or editing a page.

<ResponseField name="Page Title" type="text">
  Click the title to type in your page title.
</ResponseField>

<ResponseField name="Product Width / Height" type="number">
  Defines the final width and height of the printed PDF file. In a plain design like Business Card, Flyers, Stickers etc, this is the real dimension of the design area in physical units. Not Pixels.
</ResponseField>

<ResponseField name="Page Index" type="number">
  Allows you to insert a page in between existing pages. By default, it should be 1. If you have other pages and you want to insert a page before page 3 for instance, then you should enter 3. So your new page becomes page 3, pushing the rest further.
</ResponseField>

<ResponseField name="Bleed Lines" type="number">
  A single bleed value can be provided and will be used to demarcate cut lines.

  <Note>
    The bleed is part of the final design size here. So if you have 10cm x 12cm with a bleed of 0.5cm, the final PDF will still read 10cm by 12cm and take off 0.5cm on all edges and place the cut marks there.
  </Note>
</ResponseField>

<ResponseField name="Margin Lines" type="number">
  Shows similar to the bleed line but is shown as a solid line and not used for cuts.
</ResponseField>

<ResponseField name="Vertical and Horizontal Fold Lines" type="text">
  Lines drawn on the design canvas to guide your users on folding portions within your design. For instance, if you are designing a greeting card, such could have a horizontal line depicting where the card will be folded, but will never be printed in the final PDF file. You can provide as many fold lines as you want by using comma to delimit each. No spacing, just comma.
</ResponseField>

<ResponseField name="Page Thumbnail Image" type="image">
  There are places where the design preview is required, like on your product page. By default, we normally use the design preview but this gives you the option of setting a different picture to be used for previewing each page.
</ResponseField>

<ResponseField name="Template Image" type="image">
  Set the template image if you are creating a Template based design. [Kindly read more here](/docs/tutorial/types-of-pitchprint-designs)
</ResponseField>

<ResponseField name="Foreground Image" type="image">
  Set the foreground image if you are creating a Foreground based design. [Kindly read more here](/docs/tutorial/types-of-pitchprint-designs)
</ResponseField>

<ResponseField name="Smart Sizes" type="multi-select">
  Create different sizes for each page of the design which the customer can choose from. [Kindly read more here](https://blog.pitchprint.com/smart-sizes/)
</ResponseField>

<ResponseField name="Lock Page" type="toggle">
  Prevents the customer from editing this page.
</ResponseField>

Click the **Make Page button** to add the new page to your design.

## Item Panel

Properties of the item currently selected on the canvas.

<ResponseField name="Width, Height, XPos and YPos" type="number">
  The basic property of the selected item. You can click the padlock icon to lock the width / height ratios while editing.
</ResponseField>

<ResponseField name="Label" type="text">
  The title that's displayed for the item when a form is displayed for this design. It can also be used to pre-populate a text value with the user data when the app loads. These values are supported by default: Email, Phone, Address and Name. For example, if you have a text on the canvas and you gave it a Label _"email"_, when that design loads on the product and your user is logged in, this text will be automatically filled with the user's email address. If the user is not logged in, we will just display the value you have provided.

  On a form, this is used as the label as shown below: _Name, Title, Phone Number, Logo etc are each Labels assigned to different text elements.._

  <Frame>
    ![](https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/61ea77a88200bc052eb81123/file-b6e1k7toQH.png)
  </Frame>
</ResponseField>

<ResponseField name="Chain" type="text">
  The chain value is used to link text and photos together so they share the same value. For instance you have several email elements on the canvas, if they all have the same chain value, when one is edited, the remaining ones also get their values updated. Same with photos. You can come up with any value for a chain but they must be exact and are case sensitive. You can have multiple chains separated by comma and no spacing.

  <Note>
    This is different from the Label.
  </Note>
</ResponseField>

<ResponseField name="Index" type="number">
  An integer that allows you set the display hierarchy of items in a form. Every item has a default index value of 0, so you can have a positive or negative value. Items with higher values will be displayed first. In the form displayed above, Name has a higher value than Title.
</ResponseField>

<ResponseField name="List" type="text">
  Creates a list of elements, each item will contain a comma after to separate the elements from one another.
</ResponseField>

<ResponseField name="Tags" type="text">
  Add tags to enable extra functionalities.
</ResponseField>

<ResponseField name="Text Input Format" type="text">
  Format input text, for things like Email address, ZIP code and Phone numbers etc.

  <Note>
    Leave this field blank if you do not need it.
  </Note>
</ResponseField>

<ResponseField name="Limit Text Count" type="number">
  Limit the amount of text that can be typed into a field.

  <Note>
    Leave this field blank if you do not need it.
  </Note>
</ResponseField>

<ResponseField name="Transform Lock" type="toggle">
  The item is locked on the canvas and cannot be moved or scaled by your customer. On the admin side, you can still move or scale it, but once loaded in the product page it is locked down.
</ResponseField>

<ResponseField name="Selection Lock" type="toggle">
  Prevents clients from being able to pick this item.
</ResponseField>

<ResponseField name="Delete Lock" type="toggle">
  Prevents clients from being able to remove this item.
</ResponseField>

<ResponseField name="Hide Menus" type="toggle">
  The context menu that shows options for this element will not be displayed during customization by the customer.
</ResponseField>

<ResponseField name="Is Reference" type="toggle">
  Enabled for items that are not necessarily part of the design but that you want to use as a guide. Any item which is reference is NOT printed in the final PDF nor displayed in the design preview. You can use this to create elements that show information or as labels. This can be image, shape or text.

  <Note>
    You should lock this as well so it is not clicked and edited.
  </Note>
</ResponseField>

<ResponseField name="Hooks" type="text">
  Hooks allow items positioning to be linked together, such that when one is scaled or edited, the child's position adjusts accordingly. Kindly read more on [Hooks here](/docs/tutorial/item-hooks)
</ResponseField>

At anytime, you can click the PDF Icon on the top right hand corner to generate a PDF and see how your design will come out.
