The Page loader module is designed to allow users load additional pages into their designs from an assigned source design.

<Frame>
  <img src="https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/617276d312c07c18afddff30/file-VPO4BQgakq.png" alt="Page Loader settings with a source design selected and the add, swap, delete and start blank options" />
</Frame>

As shown above, a source design needs to be selected with multiple pages. Ensure the source design and the target design are of the same units. Other options are described as follows:

-   **Add Page:** This option when enabled, allows users to add new page from the source design into the main design.
-   **Swap Page:** This option allows the users to swap their existing page with a new one from the source design.
-   **Delete Page:** This gives users ability to delete pages from the current design
-   **Start Blank:** When enabled, this option deletes all the pages from the existing design so your users gets to start by adding pages afresh from the source design

This is how the module appears in your designer with all the options enabled..
