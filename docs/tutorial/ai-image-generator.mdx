This module allows your customers to generate AI images based on a given text prompt, with additional options such as Styles and Sizes.

It has two main functionalities namely:

1.  AI Image Generation
2.  AI Image Upscaling

**AI Image Generation**

There are three size options to choose from namely:

1.  Square
2.  Portrait and,
3.  Landscape

The module categorizes image generation into six distinct areas namely: _**Style, Art, Photography, Backgrounds, Product**_ and an additional _**Trending**_ category for the latest styles. Each category offers a set of tailored prompts, which simplifies the process of creating AI-generated images thus eliminating the process of creating your own prompts from scratch.

How does it work?

<Steps>
  <Step title="Describe the image">
    Firstly the user will describe their image using words, the more words you provide the more accurate the image. The reload icon provides a few options of random prompts that can be used for inspiration.

    <Frame>
      <img src="https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/657842fc4f53e13afbf2f03e/file-yhgQZrj79Y.png" alt="Prompt box where the user types a description of the image, with a reload icon for random prompts" />
    </Frame>
  </Step>
  <Step title="Select the image size">
    The user can then select the size for the image:

    <Frame>
      <img src="https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/6578453c4f37be75a5026e35/file-I7eR74Tfoo.png" alt="Size options for the generated image: square, portrait and landscape" />
    </Frame>
  </Step>
  <Step title="Optionally choose a Style or Category">
    _Please note this step is entirely optional_**_._** We have two options the user can select from namely: **Style** and **Category**, category consists of _**Art, Trending, Photography, Backgrounds**_ and _**Products.**_

    When a user selects the _**Style Option**_ they can apply an aesthetic OR artistic approach to the image that they are generating. The style option alters the visual representation of the final image, such as making the image resemble anime, comic books, 3D etc.

    The _**Category Option**_ on the other hand provides prompts. A prompt is a thematic starting point that guides the content of the image. Categories like Art, Trending, Photography, Backgrounds and Products offer a variety of content-based prompts, helping end-users to generate images that align with a specific subject or theme. The user also has the option of creating their own prompts instead of using our default prompts.

    While the _**Style**_ determines the look and feel of the image, the _**Category**_ determines it's subject matter and content.

    <Frame>
      <img src="https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/65b0c26b11a1ca1c986cd3d9/file-cL1jqh7ziQ.png" alt="Style and Category selectors with their available options" />
    </Frame>
  </Step>
  <Step title="Generate the image">
    After making all selections click on _**GENERATE IMAGE**_ an image will be generated and added to the canvas as well as the file uploads section so you can make use of it again in future should you wish to.
  </Step>
  <Step title="Enable the plugin in settings">
    To enable this amazing feature please go to [settings](https://admin.pitchprint.com/settings) >> Then scroll down to Plugins and Enable AI-Imaginate(BETA) as shown below. Please save your changes in order to see the plugin on the front end.

    <Frame>
      <img src="https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/65b0be2c87e88924b5fa1ff8/file-MkcmE1csri.png" alt="Plugins section of the settings page with AI-Imaginate (BETA) switched on" />
    </Frame>
  </Step>
  <Step title="Reload your layouts">
    To complete the process, reload your [layouts](https://admin.pitchprint.com/layouts). Remember to save any code elsewhere prior to performing this action.
  </Step>
</Steps>

Please note that this feature is still in **BETA mode** and we will continue to add functionality. Please reach out to us via [support@pitchprint.com](mailto:support@pitchprint.com) with any suggestions or questions.
