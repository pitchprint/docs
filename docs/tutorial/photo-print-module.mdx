This module enables your customers to easily order print copies of their photos, sourced from their social media accounts or those stored on their computers or phones, directly from your online store.

The Photo Print module has been updated to function in 3 modes which are:

1.  **Photo with Paper Type selection**
2.  **Bulk Photo Prints**
3.  **Vintage Photo Prints**

All three modes follow similar photo selection flow, starting with the welcome screen shown below:

<Frame>
  <img src="https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/5f169e9d2c7d3a10cbab09c3/file-O9GxfZKxjT.png" alt="Photo Print welcome screen where customers import or drag in their photos" />
</Frame>

This screen offers the customer the interface to import photos from various source or drag them unto the page as displayed.

Selected photos will populate the user gallery on the left panel from where they can click to add to the print collection.

### Photo with Paper Type selection

Enabling the module in this mode will allow you to create a set of preset sizes your customers can select from as well as paper types you offer to print on.

This mode is great for few photo prints where you want to offer the customer an option to select paper type on which to print with the quantity against each photo. Once the customer has added a photo, they will see the following pop-up.

<Frame>
  <img src="https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/5f16d1232c7d3a10cbab0c04/file-XyjjF6mCXG.png" alt="Pop-up for setting quantity, size and paper type for an added photo" />
</Frame>

This dialog allows them to set the **Quantity**, **Size** and **Paper type** per photo.

You can view and try out our demo by [clicking here](https://wp.demo.pitchprint.io/product/photo-prints-paper-type/)

### Bulk Photo Prints

This mode is specifically designed to enable customers bulk-order their photo prints with little hassles. No paper selection is required, they simply click to add as many photos as they want printed and set the sizing. Users can select multiple sizes of the same photo as well as set quantities on each size variation.

You can view and try out our demo by [clicking here](https://wp.demo.pitchprint.io/product/blue-collage-bulk-photo-prints/)

This also gives customers few editing features like Rotation, Filters and Position adjustment per photo. By default, the photo is placed to automatically "FIT" the size area but users can then drag and adjust to expose or hide the regions of the photo they want.

### Vintage Photo Prints

This mode allows your customers to order their prints in different designs you have created as pages. It relies exclusively on the pages inside of a design for sizing and design cues.

<Note>
  You can view and try out our demo by [clicking here](https://wp.demo.pitchprint.io/product/photo-prints-vintage/)
</Note>

Basically, the pages in that design become the sizes. So, if your design has 2 pages first landscape 10 by 5 and a second page 20 by 8, then you'll have size options of 10x5 and 20x8 for your users to select from.

In addition to the sizing, there are a few other rules to be followed in properly creating the design.

<Steps>
  <Step title="Create the photo mask">
    Create a Photo Mask. This should be a plain shape where the photo will go into. Name that mask as **"photo"** and place a dummy image in there which will be replaced by the customer's selected photo.
  </Step>

  <Step title="Add the caption text">
    Create a Caption Text and name the item **"title".** This will assist the app in finding the item which text corresponds to the caption and update this appropriately when user types in their caption.

    <Frame>
      <img src="https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/5f16db3704286306f8072886/file-YT88gXar94.png" alt="Design page containing a mask named photo and a caption text named title" />
    </Frame>

  </Step>

  <Step title="Lock the elements">
    Lock elements to prevent the customer from moving things around. This is the general configuration we advise:

    <Frame>
      <img src="https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/5f16dbce2c7d3a10cbab0cbe/file-GTTUtmPaPK.png" alt="Recommended lock configuration for the design elements" />
    </Frame>

  </Step>
</Steps>

### How to Enable Photo Print for a Design:

<Steps>
  <Step title="Create a blank design">
    To enable this module, navigate to your Designs [Page](https://admin.pitchprint.io/designs) and create a blank design with a title in a category of your choice. The design can have just a single blank page. This will eventually be removed.

    <Frame>
      <img src="https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/5b28dd812c7d3a0fa9a32674/file-6JpI8VU4pW.png" alt="Blank single-page design created with a title in a category" />
    </Frame>

  </Step>

  <Step title="Open the design configuration">
    Once you have saved the design, find it in the list, mouse over it and click the **Configure Icon** as shown:

    <Frame>
      <img src="https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/5b28ddfd0428632c466b0c73/file-RYFOkDLAEV.png" alt="Configure icon shown when hovering over a design in the list" />
    </Frame>

  </Step>

  <Step title="Enable the Photo Print module">
    This should pop up the panel shown below. Navigate to the **Modules Tab**, there you will find the Photo Print module, Click to enable it.

    <Frame>
      <img src="https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/5b28de7b2c7d3a0fa9a32679/file-46wTBaPTcj.png" alt="Photo Print module listed in the Modules tab of the design configuration panel" />
    </Frame>

  </Step>

  <Step title="Add your print sizes">
    Now you can give it a title, and choose the measuring unit you'd prefer. Next click the **Add a Size** button, you can add as many sizes as you require.

    <Frame>
      <img src="https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/5b28df410428632c466b0c7a/file-OZRnHkDBkm.png" alt="Add a Size button used to add print sizes to the module" />
    </Frame>

  </Step>

  <Step title="Add your paper types">
    Lastly click the **Add a Paper Type** button to add the types of printing paper you have.

    <Frame>
      <img src="https://s3.amazonaws.com/helpscout.net/docs/assets/58f1ec6d2c7d3a52b42f8254/images/5b28e2210428632c466b0c86/file-dtNLkG7rQC.png" alt="Add a Paper Type button used to add the papers you print on" />
    </Frame>

  </Step>

  <Step title="Save the configuration">
    Click the **Save** button.
  </Step>
</Steps>
