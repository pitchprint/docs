## PPCLIENT Properties

You can define project-specific customization properties using the global `window.PPCLIENT` object. These can be set in the following ways:

```javascript
window.PPCLIENT = {};
// or individually:
window.PPCLIENT["propertyName"] = "value";
```

<ResponseField name="customImageSelector" type="string">
  Custom CSS selector for preview images in the project view.
</ResponseField>

<ResponseField name="customThumbSelector" type="string">
  Custom CSS selector for preview thumbnails in the project view.
</ResponseField>

<ResponseField name="smartSizeSelector" type="string">
  Custom CSS selector for the Smart Sizes module (e.g. for selecting sizes).
</ResponseField>

<ResponseField name="quantitySelector" type="string">
  Custom CSS selector for the quantity input or page count selector.
</ResponseField>

<ResponseField name="userAccountPath" type="string">
  Custom URL path to direct users to view saved designs.
</ResponseField>

<ResponseField name="customAccountDivSel" type="string">
  Custom selector to embed the Saved Designs section on a page.
</ResponseField>

<ResponseField name="hideObserverablePreview" type="boolean">
  Whether to hide preview images in observable design states.
</ResponseField>

<ResponseField name="createDesignLabel" type="string">
  Affects the label used for design creation.

  <Note>
    Behaviour is platform-specific and not fully documented.
  </Note>
</ResponseField>

<ResponseField name="customCartButtonSelector" type="string">
  Custom CSS selector for the Add to Cart button.
</ResponseField>

<ResponseField name="langEdits" type="object">
  Object to override language labels and text in the UI.
</ResponseField>

<ResponseField name="customizationRequired" type="boolean">
  If `true`, users must customize the design before adding it to cart.
</ResponseField>

```javascript
window.PPCLIENT = {
  customImageSelector: ".product-preview img",
  customThumbSelector: ".preview-thumbnails img",
  smartSizeSelector: "#smart-size-options",
  quantitySelector: "#page-count",
  userAccountPath: "/my-account/saved-designs",
  customAccountDivSel: "#saved-designs-wrapper",
  hideObserverablePreview: true,
  createDesignLabel: "Create Design",
  customCartButtonSelector: ".add-to-cart-btn",
  langEdits: {
    "Customize": "Personalize",
    "Add to Cart": "Buy Now"
  },
  customizationRequired: true
};
```
